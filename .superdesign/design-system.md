# Linia design system

## Product

**Linia** — open European bus/train timetable hall. Search A→B (and via / station board), read connections like a departure board, share public links, print/PDF tickets. No accounts, no booking. Powered by Transitous/MOTIS. 13 locales.

## Shipped visual DNA — Industrial Departure Board

- Metaphor: **charcoal enamel station board** — LED amber times, hazard red for delays only
- Fonts: **Barlow Condensed** (display) + **IBM Plex Sans** (body) + **IBM Plex Mono** (stamps/times)
- Light cool enamel `#d8dee8` / ink `#12151a` / amber `#ffb020`
- Dark charcoal `#0c0e12` / off-white `#e8edf2` / amber LED `#ffb020`
- Hazard: `#e11d2e` / `#ff3b30` only for delays & cancellations
- Components as **stamps** and **tickets** (destination-board rows), not parchment cards

## Anti AI-slop (locked)

**Avoid**
- Warm cream `#F4F1EA`-adjacent grounds with terracotta/serif hero
- Fraunces italic / cream paper stationery look
- Purple/indigo gradients, glassmorphism glow, rounded-full pill clusters
- Inter / Roboto / Space Grotesk / generic SaaS dashboards
- Broadsheet hairline newspaper grids

**Keep (product, not paint)**
- One first-viewport composition (desk + map), brand “Linia” as hero signal
- Stamp/ticket interaction language (pressable filters, selected ticket)
- Live board clarity: times mono, delays obvious, share/print
- Light + dark themes
- Map as real visual anchor (route on European wall)

## Direction detail

**Palette:**
- Ground: charcoal enamel `#12151a` / `#0c0e12`
- Raised panels: matte `#1a1f27` with hairline `#2a3340`
- Primary text: cool off-white `#e8edf2`
- Muted: `#8b97a8`
- **LED amber** `#ffb020` for times, live lamp, key CTAs
- Signal hazard: `#ff3b30` only for delays/cancellations
- Map: dark ink tiles, amber route stroke

**Type:**
- Display / brand: **Barlow Condensed** — never Fraunces italic, never Inter
- Body: **IBM Plex Sans**
- Times / stamps: **IBM Plex Mono** — tabular nums, LED-like tracking

**Surfaces:**
- Zero cream paper, zero soft multi-layer shadows, zero rounded-full pills
- Flat enamel panels, 1px metal rules, rubber-stamp buttons with hard press states
- Tickets = destination-board rows, not parchment cards

**Unforgettable detail:** amber LED clock + pulsing live lamp on charcoal enamel mast.

**Layout (unchanged IA):** brand Linia as hero; desk (search + results) | wall map; stamps for filters; share/print stay.
